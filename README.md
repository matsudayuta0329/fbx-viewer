# fbx-viewer
## ソフト概要
サーフェスモデルでの表示、各種頂点情報での表示、UVの表示に対応した
3Dオブジェクト(fbx)用のビュアー
単一のファイルの表示を行える
C++とWinUIを使用する

### 3Dビュー
オブジェクトを設定した表示方式で表示する
拡大縮小、視点移動、視点回転を行える
頂点をホバーすることでホバーメニューが表示される
頂点情報表示で選択できるすべてのデータがテキストとして表示される

### 2Dビュー
UV上のポリゴン内部を塗り、頂点色やUVを補間して3Dビューと同じシェーダーで表示する。
全表示モードで、3D表示をUVへベイクした画像のような見た目にする。サーフェスの陰影・フレネルには3Dビューの視点を使う。
頂点の点表示は共通の「頂点を表示」を有効にした場合だけ重ねる。

## ビルドと起動

Windows 10 バージョン2004（19041）以降 / Windows 11、x64向けのデスクトップアプリです。

必要な開発環境:

- Visual Studio 2022 または 2026 の「C++によるデスクトップ開発」
- Windows SDK 10.0.26100.0
- Visual Studioに同梱されるvcpkg、Git、インターネット接続（初回の依存関係復元用）

リポジトリのルートでPowerShellから実行します。

```powershell
./scripts/build.ps1 -Configuration Release
./build/x64/Release/FbxViewer.exe
```

スクリプトがVisual Studioの位置とツールセットを検出します。NuGetからWinUI 3 / C++/WinRTを、vcpkgからAssimpを復元します。初回はAssimpとその依存ライブラリのコンパイルに時間がかかります。

実行ファイルだけでは起動できません。配布する場合は `build/x64/Release` 全体をまとめてください。Windows App SDKは自己完結型で同梱されます。C++ランタイムにはMicrosoft Visual C++ 再頒布可能パッケージ（x64）が必要です。

## 操作

| 操作 | 3Dビュー（左） | UVビュー（右） |
| --- | --- | --- |
| 左ドラッグ | 視点回転 | 平行移動 |
| 右・中ドラッグ | 平行移動 | 平行移動 |
| ホイール | 拡大縮小 | 拡大縮小 |
| ダブルクリック | 視点を初期位置へ | UV 0〜1を表示 |
| 頂点ホバー | 頂点属性を表示 | 頂点属性を表示 |

- 「ファイル → 開く…」またはウィンドウへのドロップでFBXを1つ開きます。読み込み中も画面操作できます。読み込みに失敗した場合は、直前のモデルを保持します。
- 右上で「サーフェス」「UVスクロール」「頂点情報」を切り替えます。「表示設定」はモードごとに切り替わります。
- ツールバー左端に「ファイル」、右端に排他的な3つの表示形式ボタンと「表示設定」が並びます。
- 「表示設定」の「全体を表示」で両方のビューをリセットします。
- UVの展開に使うチャンネルは「表示設定 → UVマップ」で切り替えます。ビュー上に常設の選択欄は置きません。頂点情報モードでは同じポップアップ内の「頂点情報」からTEXCOORD0〜7 / COLOR0〜7などを直接選びます。
- 頂点情報ではNormal、Position、TEXCOORD0〜7、Index、Tangent、Bitangent、COLOR0〜7を選べます。値のない属性はマゼンタで表示します。
- Normal / Tangent / Bitangentは−1〜1をRGBの0〜1へ変換します。Positionはモデル全体の境界範囲、Indexは読み込み後の頂点順で正規化します。TEXCOORD / COLORは0〜1に制限して色へ変換します。無彩色はRGBの輝度です。ホバー情報には色変換前の数値を表示します。
- サーフェスの透過時は深度テスト・深度書き込みを無効にし、通常の色に透明度35%を適用します。
- UVビューは全モードで三角形の内部を塗ります。頂点情報は各頂点色を補間し、UVスクロールとサーフェスは補間されたUV・法線・位置を使って3D側と同じシェーダーで描画します。UVの重なりは描画順で重なります（透過時は合成）。これはビュー表示であり、画像ファイルの書き出し機能ではありません。

## 実装構成と範囲

- `src/Main.cpp`: WinUI画面、ファイル入力、非同期読み込み、入力イベント、表示設定
- `src/Model.*`: Assimp読み込み、ノード変換、属性の色変換、ホバーテキスト
- `src/Renderer.*`: Direct3D 11 / SwapChainPanel、HLSLシェーダー、カメラ、頂点選択
- `src/Shaders.h`: アプリと自動テストで共有するHLSLソース
- `tests/ModelTests.cpp`: 実際のASCII / バイナリFBXを生成して行う読み込み・属性の回帰テスト

FBX内のメッシュをノード変換込みで同時に表示します。モデルの座標系を維持し、カメラ計算時だけ中心と大きさを正規化します。欠落法線は三角形から生成します。IndexはAssimp読み込み後の頂点番号です。ホバーのPositionはノード変換後のワールド座標です。

アニメーション・スキニング再生、マテリアルや外部画像の再現、モデル編集・保存は対象外です。メッシュの静的な状態を表示します。UVがないモデルも3Dで表示できます。欠落したUVチャンネルの2Dビューは空になります。

ファイルサイズは512 MiB、展開後の頂点数は500万までです。この上限内でも使用可能なCPU/GPUメモリに依存します。GPU転送に失敗すると前のモデルへの復旧を試み、復旧にも失敗した場合は表示をクリアします。ホバー選択はCPUで頂点と三角形を調べるため、大きいモデルでは応答が遅くなる場合があります。GPUデバイスが失われた場合はエラーを表示して描画を停止します。その場合はアプリを再起動してください。

## 検証

```powershell
./scripts/build.ps1 -Configuration Debug -Test
```

実際のアプリの起動から左右ビューの初回描画までを検証するには、アプリをビルド後に以下を実行します。

```powershell
./scripts/smoke-test.ps1 -Configuration Release
# Debug版をビルドした場合
./scripts/smoke-test.ps1 -Configuration Debug
# 頂点ホバー・左右ビュー切り替え・表示モード変更を60フレーム検証
./scripts/smoke-test.ps1 -Configuration Release -Hover
```

起動テストは実アプリを `--smoke-test` 付きで起動し、両方のビューを描画できた場合に終了コード0で閉じます。起動時の診断情報は実行ファイルと同じフォルダーの `startup.log` に記録します。

`-Hover` は合成メッシュを使って実アプリの頂点選択・属性表示・非表示を繰り返します。左右ビュー間の切り替え、全表示モード、画面端での表示位置、不正な頂点番号、ホバー表示中の終了も検証します。

日本語ファイル名、ノード変換（負のスケールを含む）、ASCII / バイナリFBX、複数UV、頂点色、法線生成、属性の色変換、不正・空・存在しないファイルと、VS / PS / GSのHLSLコンパイルを確認します。生成したFBXは `build/test-data` に残るため、手動の画面確認にも利用できます。

手動確認項目:

1. `build/test-data/日本語モデル.fbx` を開き、左右に面を塗った三角形が見えること。
2. 回転・平行移動・ズーム・全体表示が機能すること。
3. UVスクロールの方向・速度・グリッド数の変更が反映されること。
4. Normal / Position / Index / TEXCOORD1 / COLOR0と無彩色表示を切り替え、UV側の頂点色も変わること。
5. 頂点の表示・サイズ・色、透過、頂点ホバー、TEXCOORD切り替えを確認すること。
6. `no-attributes.fbx`、`broken.fbx`、複数ファイルのドロップを試し、欠落属性やエラーが明示されること。

`-Hover` 実行テストにはUV描画のGPU画素検証も含まれます。RGBの3頂点を持つ三角形で、重心の補間色、頂点寄りのグラデーション、ポリゴン外の背景、サーフェス内部の塗りを確認します。

### 起動不具合の修正（2026-09-27）

WinUIテーマをアプリのコンストラクター内で読み込んでいたことと、XAML型情報プロバイダーの未実装により、起動時にクラッシュしていました。テーマの読み込みを `OnLaunched` へ移し、`IXamlMetadataProvider` を実装しました。Debug・Release両方でビルド（警告・エラー0件）と、起動から左右ビューの初回描画までの実行テストが成功しました。入力操作・FBX表示の見た目の手動確認は、この起動テストには含みません。

### 頂点ホバーの安定化（2026-09-27）

画面ツリーに所属していないToolTipを直接開く処理で「ポインターが無効です」の例外を再現しました。頂点情報を同じ画面ツリー内の表示パネルへ変更し、独立したポップアップの生成・開閉をなくしました。パネルはマウス操作を遮らず、ウィンドウ内に収まる位置に表示します。ファイル読み込み、視点操作、ビューサイズや表示形式の変更では非表示にします。選択項目が一時的に未選択になる場合や、無効な頂点番号も検査します。

修正前はホバー実行テストの最初の表示で無効ポインター例外となり終了コード1でした。修正後はDebug・Releaseで60フレームのホバー検証が成功しています。

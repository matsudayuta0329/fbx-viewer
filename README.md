# fbx-viewer
## ソフト概要
サーフェスモデルでの表示、各種頂点情報での表示、UVの表示に対応した
3Dオブジェクト(fbx)用のビュアー
単一のファイルの表示を行える
C++とWinUIを使用する

## 詳細機能、構成
上にツールバー、左右で３Dビュー2Dビューとして分かれたUI構成
メニューの開くか、ファイルをウィンドウ内にドラッグ＆ドロップするとfbxを開ける

### 表示形式切り替え
下の表示設定を含めblenderのメニューを参考
サーフェスモデル(通常の灰色をベースとし、少し明るい灰色をフレネルで入れる表示)
UVスクロール表示(グリッドテクスチャをメッシュのUVに沿ってスクロールさせる表示)
頂点情報表示(メッシュの各頂点情報を選択して無彩色の明るさか、xyzをrgbに変換し表示する)

### 表示設定
ポップアップメニュー
表示形式ごとに異なる設定を表示する
共通
頂点表示(各頂点の位置に白いドットを置くか
頂点サイズ(上記のドットのサイズ)
頂点色(頂点の表示色)
サーフェースモデル
- 透過するか(zバッファを無効にし非半透明時の色を維持したまま半透明にする)
UVスクロール表示
- スクロールの方向
- 時間に対する移動量
- グリッドの数
頂点情報表示
- どの情報を表示するか(normal position uv座標　頂点index TEXCOORD+番号等)

### 3Dビュー
オブジェクトを設定した表示方式で表示する
拡大縮小、視点移動、視点回転を行える
頂点をホバーすることでホバーメニューが表示される
頂点情報表示で選択できるすべてのデータがテキストとして表示される

### 2Dビュー
各表示の時の各頂点の表示色に対応する色が対応するUV上の頂点位置に表示される
ただしサーフェス表示の時はメッシュのUV平面上のエッジのワイヤーフレームを表示する
